# MYHD IPTV MANDO

مشروع موقع ويب مستقل لإدارة وعرض باقات MYHD IPTV MANDO.

## الهوية
- واجهة عربية RTL.
- تصميم أسود وذهبي فاخر.
- صفحات الموقع، حساب العميل، ولوحة الإدارة.

## فصل المشاريع
هذا المستودع مستقل عن MANDO SPORT وعن متجر أجهزة التحكم. لا تربطه بقاعدة بيانات MANDO SPORT.

## الخطوات التالية
1. إضافة ملفات واجهة الموقع.
2. إنشاء مشروع Supabase مستقل خاص بـ MYHD IPTV MANDO.
3. ربط بيانات المشروع العامة الآمنة (Project URL و Publishable Key).
4. إدخال صور البطاقات والأسعار الأصلية التي اعتمدها صاحب المشروع.
5. اختبار تسجيل الحسابات وإدارة الباقات والطلبات قبل النشر.

## تنبيه
لا تضع مفاتيح service_role أو أي أسرار في ملفات الواجهة أو المستودع.
لا تُعتبر عمليات الدفع أو تفعيل الاشتراك جاهزة قبل تنفيذها واختبارها.
